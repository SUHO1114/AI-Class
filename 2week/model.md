# AI-Class: Classification(분류)
### 1. 로지스틱 회귀 모델(Logistic Regression)
* **작동원리**: 입력데이터($X$)의 선형 조합을 구한 뒤, 이를 시그모이드(Sigmoid) 함수에 통과시켜, 0과 1사이의 확률값으로 변환. 보통 확률이 0.5보다 크면 `1(당뇨병)`, 작으면 `0(정상)`으로 판단.
* **특징**
  * **장점**: 모델이 가볍고 계산 속도가 매우 빠름.
  * **단점**: 데이터가 직선이나 평면으로 깔끔하게 나뉘지 않는 복잡한 관계(비선형)일 때는 성능이 떨어짐.

### 2. 결정 트리(Decision Tree)
* **작동원리**: "혈당이 120 이상인가?", "BMI가 25 이상인가?"와 같은 질문을 던져 데이터를 계속해서 자식 노드로 분할. 가장 순수하게 데이터를 나누는 기준을 자동으로 찾음.
* **특징**
  * **장점**: 사람이 이해하기 가장 쉬움, 데이터 전처리의 영향도 적게 받음.
  * **단점**: 트리가 깊어질수록 학습 데이터에만 너무 과하게 맞춰지는 **과적합(Overfitting)** 문제 발생.

### 3. 랜덤 포레스트(Random Forest)
* **작동원리**: "훈련데이터에서 무작위로 뽑은 샘플"과 "무작위로 선택한 특징들"을 사용하여 **수백개의 서로 다른 결정 트리**를 만듦. 그 후 모든 트리의 예측 결과 중 가장 많이 나온 값을 최종 정답으로 선택.
* **특징**
  * **장점**: 결정 트리의 단점인 과적합을 효과적으로 해결, 대부분의 데이터셋에서 매우 높은 정확도.
  * **단점**: 모델이 복잡해져서 학습 속도가 단일 트리보다 느리고, "왜 이런 결과가 나왔는지" 설명하기 어려움.
