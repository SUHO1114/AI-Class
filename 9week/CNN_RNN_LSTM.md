
## 1. CNN (Convolutional Neural Network, 합성곱 신경망)
**이미지의 공간적 구조(Spatial Structure)를 파악하여 유의미한 특징을 추출하는 신경망**

### 개념
* **기존 방식의 한계**: 이미지를 1차원 벡터로 펼치는 **평탄화(Flatten)**를 하면, 인접한 픽셀 간의 관계(공간 정보)가 파괴됨.
* **해결책**: 필터(Filter/Kernel)를 사용하여 이미지 위를 슬라이딩하며 곱하는 **컨볼루션(합성곱) 연산**을 통해, 이미지의 공간적인 특징(선, 면, 형체)을 보존하며 추출.

### 구성 요소 및 특징
* **필터(Filter)**
    * 필터는 이미지의 특징을 찾는 역할 수행.
    * 주로 가중치가 저장된 **3x3, 5x5와 같은 배열**로 구현.
    * 초기에는 **랜덤값**으로 시작하지만, 학습을 통해 데이터에 최적화된 **가중치(Weights)**를 갖게 됨.
* **풀링(Pooling)**
    * 필터 크기에 따라서 생성되는 가중치/바이오스는 더 증가하게 됨.
    * 컨볼루션 연산을 통해 증가한 정보의 크기를 **줄이는 것**이 풀링의 목적.
    * **최대 풀링(Max Pooling)**: 특정 맵의 특정 영역에서 가장 가중치가 큰 값을 추출하는 방식.
    * **평균 풀링(Average Pooling)**: 영역의 가중치의 평균값을 추출하는 방식.
    * 정보 요약뿐만 아니라 사물의 위치가 이미지 안에서 조금 바뀌더라도 동일한 특징으로 인식하게 해주는 **이동 불변성(Translation Invariance)** 또한 존재.
* **보폭(Stride)과 패딩(Padding)**
    * **Stride**: 필터를 얼마나 큰 보폭으로 건너뛰며 적용할지 결정. Stride가 커지면 출력되는 결과(Feature Map)의 크기는 작아짐.
    * **Padding**: 이미지 가장자리에 0을 채우거나(**same**) 아예 처리하지 않는 방식(**valid**)으로 필터를 적용하지 못하는 이미지의 가장자리를 처리하는 기법.

## 2. RNN (Recurrent Neural Network, 순환 신경망)
**데이터의 순서(Sequence)와 문맥을 파악하여 과거의 정보를 현재에 반영하는 신경망**

### 개념
* **기존 방식의 한계**: 일반적인 신경망(DNN)은 입력 데이터가 독립적이라고 가정하므로, 문장이나 시계열 데이터처럼 **앞뒤 순서가 중요한 정보**를 처리하기 어려움.
* **해결책**: 출력값이 다시 입력값의 일부로 들어가는 **순환(Recurrence) 구조**를 채택하여, 이전 단계의 정보를 '기억'으로 남겨 현재 계산에 활용.

### 구성 요소 및 특징
* **은닉 상태 (Hidden State)**
    * 과거의 정보를 압축해서 들고 있는 메모리 역할을 수행.
    * 매 시점($t$)마다 갱신되며, 이전 시점의 은닉 상태($h_{t-1}$)와 현재의 입력($x_t$)을 조합하여 새로운 은닉 상태($h_t$)를 만듦.
* **가중치 공유 (Weight Sharing)**
    * RNN은 모든 시점에서 **동일한 가중치($W$)**를 반복해서 사용.
    * 이는 데이터의 길이에 상관없이 모델을 유연하게 적용할 수 있게 해주며 학습 파라미터를 줄여줌.
* **장기 의존성 문제 (Long-Term Dependency)**
    * 데이터가 길어질수록 앞쪽의 정보가 뒤로 갈수록 희미해지는 **기울기 감쇠(Gradient Vanishing)** 현상이 발생.
    * 이 문제를 해결하기 위해 **LSTM**이나 **GRU** 같은 모델이 등장.
* **유연한 입출력 구조**
    * **One-to-Many**: 이미지 캡셔닝 (이미지 1개 입력 → 설명 문장 출력)
    * **Many-to-One**: 감성 분석 (리뷰 문장 입력 → 긍정/부정 판단 출력)
    * **Many-to-Many**: 기계 번역 (한국어 문장 입력 → 영어 문장 출력)

## 3. LSTM (Long Short-Term Memory, 장단기 메모리)
**RNN의 치명적인 단점인 '장기 의존성 문제'를 해결하기 위해 '게이트' 구조를 도입한 신경망**

### 개념
* **기존 방식의 한계**: 일반 RNN은 정보와 정보 사이의 거리가 멀어질수록 앞쪽의 정보를 잊어버리는 **기울기 감쇠(Gradient Vanishing)** 현상이 발생하여 긴 문맥을 파악하지 못함.
* **해결책**: 핵심 정보를 보존하는 **셀 상태(Cell State)**와 정보를 제어하는 **3개의 게이트(Gate)**를 추가하여, 어떤 정보를 잊고 어떤 정보를 기억할지 스스로 결정.

### 구성 요소 및 특징
* **셀 상태 (Cell State)**
    * 컨베이어 벨트와 같이 전체 시퀀스를 관통하며 흐르는 통로.
    * 게이트들의 제어를 통해 정보가 큰 변형 없이 전달되므로, 아주 오래전의 정보도 현재까지 유지 가능.
* **3가지 핵심 게이트 (Gating Mechanism)**
    * **망각 게이트 (Forget Gate)**: 과거의 정보 중 불필요한 것을 얼마나 삭제할지 결정.
    * **입력 게이트 (Input Gate)**: 현재 들어온 새로운 정보 중 어떤 것을 셀 상태에 저장할지 결정.
    * **출력 게이트 (Output Gate)**: 업데이트된 셀 상태를 바탕으로 다음 은닉 상태($h_t$)로 보낼 값을 결정.
* **장기 의존성(Long-Term Dependency) 해결**
    * 게이트 구조 덕분에 수백 개의 시점(Time-step) 이전의 데이터도 효과적으로 기억할 수 있어, 긴 문장의 번역이나 복잡한 시계열 예측에 탁월.
* **복잡도와 계산량**
    * RNN에 비해 내부 연산이 복잡하고 파라미터 수가 많아 학습 속도가 상대적으로 느리다는 단점 존재.
